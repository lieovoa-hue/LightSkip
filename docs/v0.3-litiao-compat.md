# 轻跳 v0.3：李跳跳规则兼容、二次弹窗与鸿蒙诊断

## 1. 李跳跳仓库结论

`rongzhiy/LiTiaotiao` 不是源码仓库：

- 根目录只有 `README.md`、`AllRules.json` 和 3 个 APK；
- 没有许可证文件；
- APK 使用加固壳（`com.tencent.StubShell.TxAppEntry`、加密 assets），静态分析只能看到加载器和 Manifest；
- 因此轻跳没有复制其业务代码，而是按公开规则格式和无障碍配置做兼容实现。

参考的公开规则库：

- `Snoopy1866/LiTiaotiao-Custom-Rules`
- `AllRules.json` / 单 App `readme.md`

## 2. 规则格式

`AllRules.json`：

```json
[
  {
    "1994036591": "{\"popup_rules\":[{\"id\":\"广告\",\"action\":\"跳过\"}]}"
  }
]
```

- 数字键是 `packageName.hashCode()`；
- 值是一个 JSON 字符串；
- `popup_rules` 中每条规则包含 `id`、`action`；
- 支持 `&`（同一节点包含多个片段）、`|`（任一分支）、`=`（精确匹配）、`GLOBAL_ACTION_BACK`；
- `times`、`delay_popup`、`click_way_popup` 是高级字段，轻跳保存但弹窗场景以一次点击为主。

单 App：

```json
{"popup_rules":[{"id":"发现新版本","action":"iv_cancel"}]}
```

轻跳导入时：

- 全部规则按已安装 App 哈希匹配；
- 单 App 规则让用户选择所属 App；
- 只保存本机已安装 App；
- 导入后自动打开规则模式并把匹配 App 加入守护清单；
- 学习规则和导入规则分开存储，互不覆盖。

## 3. 二次弹窗

李跳跳的关键差异不是“更激进的 X 识别”，而是：

- 无障碍事件类型更宽；
- 内容变化持续监听；
- 规则按“触发节点 → 动作节点”匹配；
- 不要求弹窗一定是一个新窗口。

轻跳 v0.3 的处理：

- 目标 App 前台且存在规则时，保留内容变化监听；
- 内容变化先防抖，再启动最多 2 次扫描的探针；
- 探针最多每 2 秒一次；
- 每个探针最多 400 节点、14 层；
- 在同一个窗口内匹配触发器和动作；
- 同窗口没有动作时，只有在全窗口唯一匹配时才跨窗口兜底。

## 4. 小米 / Redmi

重点兼容：

- 短会话在 Xiaomi/Redmi/POCO 上使用全事件类型；
- 空闲时保留内容事件用于缺失窗口状态兜底；
- 同时参考 `event.packageName` 和 `rootInActiveWindow.packageName`；
- 允许扫描 `com.miui.systemAdSolution`、`com.miui.msa.global`、`com.xiaomi.ad`；
- Android 12+ 提供 `isAccessibilityTool` 配置；
- 诊断记录 root/window 包名。

仍需要 Redmi K70 / HyperOS 真机复测，不能仅凭代码判断已修复。

## 5. 鸿蒙 / HarmonyOS

### 可安装的情况

HarmonyOS 2/3/4 仍兼容 Android APK。可能的失败点：

- 无障碍显示开启但未绑定；
- 后台/自启动限制；
- 只投递部分事件；
- 广告处于系统窗口，节点不可读；
- 点击/手势受限。

### 不可安装的情况

HarmonyOS NEXT/5+ 不兼容 Android APK，轻跳无法运行；需要 HarmonyOS 原生应用。

### 用户诊断流程

1. 打开目标 App，等广告出现。
2. 回到轻跳 → 设置 → 诊断与反馈。
3. 查看 `diagnosis`。
4. 点「分享诊断」，把文本发给开发者。

报告会区分：

- 服务未连接；
- 完全没有无障碍事件；
- 有事件但没有目标窗口事件；
- 进入扫描但没有候选；
- 有候选但点击失败；
- 未发现明确故障。

开发者辅助命令：

```powershell
adb shell getprop | findstr /i "harmony emui hw_sc"
adb shell dumpsys accessibility
adb shell dumpsys activity top
adb shell logcat -d | findstr /i "lightskip Accessibility"
```
